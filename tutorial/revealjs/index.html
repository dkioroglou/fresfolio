Installation

Installation command 

                    pip install fresfolio
To install fresfolio, run the installation command in your terminal. Please note, this command assumes Python is already installed in your system.

Initialization

Initialization command 

                    fresfolio init
Generated resources 

                        fresfolio
                        ├── fresfolio.db
                        └── projects
Before start using fresfolio, run the initialization command to create the necessary directories. This creates the fresfolio directory, its database and a directory for storing projects.
