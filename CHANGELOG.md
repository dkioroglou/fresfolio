# v0.3.3 New features and bugfix Release
This is a bug fix release for various issues discovered after the release v0.3.2. Also new features have been added.

## What's Changed
* FEATURE: Omilayers tables can be viewed with perspective.js.
* FEATURE: AI responses using API key got incorporated.
* OPTIMIZED: fresfolio traceback gets logged and can be viewed with dedicated log viewer.
* OPTIMIZED: installation got split into core, extra and full.
