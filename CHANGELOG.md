# v0.3.4 New features and bugfix Release
This is a bug fix release for various issues discovered after the release v0.3.3. Also new features have been added.

## What's Changed
OPTIMIZED: added keybinding "Alt+h" to toggle AI chat drawer.
FEATURE: Quasar editor has been replaces with ACE editor for editing sections.
OPTIMIZED: AI chat can be cleared without deleting the chat sections.
OPTIMIZED: AI prompt @file directive can now accept full-paths.
OPTIMIZED: AI prompt now has @stdout directive where the response will be written.
