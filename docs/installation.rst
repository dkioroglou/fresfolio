Installation
============

Core installation
------------------

To install *fresfolio* run:

.. code-block:: bash

    pip install fresfolio

**Note**: this installs the core functionality of *fresfolio* that is sufficient to create and manage notebooks, chapters and sections.

.. _installation-process:

Extended installation
---------------------

To take advantage of the full functionality of *fresfolio*, install the full version:

.. code-block:: bash

    pip install fresfolio[full]

or if *fresfolio* is already installed, install the extra functionality:

.. code-block:: bash

    pip install fresfolio[extra]
