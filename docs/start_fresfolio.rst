Start fresfolio
===============

To start *fresfolio*:

.. code-block:: bash

   fresfolio start

then in your favorite browser go to ``http://127.0.0.1:5000``.

The default port is 5000. You can specify a different port with the ``-p`` option:

.. code-block:: bash

   fresfolio start -p [PORTNUMBER]

You can broadcast *fresfolio* in your local network using the flag ``--broadcast``:

.. code-block:: bash

   fresfolio start --broadcast


.. note::

   *fresfolio* has been developed and tested using Google Chrome. While it is expected to function in other modern browsers, full compatibility  
   has not been extensively verified.
